# Gig.is

نسخة تجريبية لمحرك اكتشاف الخدمات الرقمية المستقلة دون ذكاء اصطناعي.

- افتح `index.html` عبر GitHub Pages.
- عدل `data/services.json` لإضافة الخدمات.
- كل خدمة تتضمن `id`, `name`, `category`, `level` (0 مبتدئ، 1 متوسط، 2 متقدم), `description`, `deliverable`, `tools`.
- النتائج مبنية على مطابقة المجال ومستوى الخبرة فقط؛ لا يوجد API أو تسجيل دخول.
- بيانات الخدمات العشر أمثلة أولية للمراجعة وليست قاعدة كاملة مستخرجة من الأرشيف.
